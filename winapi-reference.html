Dynamic API Resolution
PEB walk → parse EAT → hash names → resolve at runtime — Lazarus 3CX, Silver Fox
SEEN INLazarus 3CXVoidsSealerSilver Fox APT
// API CALL CHAIN
01
PEB walk InLoadOrderModuleList
Walk PEB.Ldr to find kernel32 / ntdll base address
↓
02
Parse IMAGE_EXPORT_DIRECTORY
Read AddressOfNames and AddressOfFunctions arrays
↓
03
Hash each export name ROR13/DJB2
Compare against hardcoded target hash — no strings in binary
